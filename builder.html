Matières

Peindre, Zone ou Remplir : les bords se font tout seuls. Gomme : repeint de l'herbe.

Sols : Peindre, Zone ou Remplir. Murs : la bande entière, de la case cliquée vers le bas. Gomme : retire les meubles, garde le sol.

Éléments

Clic sur la carte pour poser (contour rouge : pas ici, la raison s'affiche en bas). Une maison choisie, au-dessus d'une maison de la carte : contour bleu, clic pour la remplacer (porte sur porte). Gomme sur un élément : il est retiré.

Clic dans la pièce pour poser un meuble (contour rouge : pas ici, la raison s'affiche en bas). Gomme sur un meuble : il est retiré.

Écarts

Assets qui s'écartent de leur famille (scripts/audit_assets.py). Clic sur une vignette : la voir sur la carte. « Supprimer » : retirée d'un clic (Ctrl+Z pour annuler).

Personnages

Glisse un personnage sur la carte pour changer sa place (ou choisis-le, puis les flèches du clavier). Ses trajets dans l'histoire ne changent pas : il part de sa nouvelle place vers les mêmes endroits.
